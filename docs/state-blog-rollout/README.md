# State blog rollout

This branch adds 55 bilingual articles and expands the existing Georgia DSCR guide, covering all 50 states for DSCR and GA, AL, TN, FL, NC and SC for Family Opportunity Mortgage. English and Spanish indexes include a state directory. New URLs have canonical and reciprocal language metadata, BlogPosting data, sitemap entries and extension redirects.

New articles were generated from the retained bilingual briefs using the existing blog publisher. Family pages use the local blog navigation script, with no advertising scripts, pixel fallback or forms. Their referrer policy prevents passing the originating family article URL to linked pages. Published article shells use the site's residential licensing disclosure. Spanish place names and the Family Opportunity product name are recognized by the casing check.

The manifest maps every topic. The briefs and source register retain the researched content. Georgia retains its existing URL, article and original publication date, with the local review sections added once. Existing Georgia illustrative calculations were outside this change.

The rollout is prepared for review, not yet deployed to production. Article dates currently reflect September 12, 2026; set the actual release date if publication occurs later. Native Spanish and final mortgage-editor review remain pending. No ranking or AI-answer placement is promised. Automated coverage and tracking checks are in tests/state-blog-rollout.test.mjs and run with the site's normal check command.
